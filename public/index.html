Zeabur · 部署成功

容器已上線，網站內容尚未匯入

這是一個佔位頁面。Caddy 已正常服務 public/ 目錄，代表部署管線本身沒有問題。

接下來把 Wix 網站抓下來覆蓋這個目錄即可：

  1. 在有對外網路的電腦上 clone 本專案
  2. 執行 npm install && npx playwright install chromium
  3. 執行 npm run capture（抓取並改寫 Wix 網站）
  4. 執行 npm run audit 確認沒有殘留的 Wix 依賴
  5. 把 public/ 提交並推送，Zeabur 會自動重新部署
詳細步驟請見專案根目錄的 README.md。
